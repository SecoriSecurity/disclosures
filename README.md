# Disclosures

Findings by Secori that have been reported to the maintainer and fixed or otherwise
concluded. One file per finding, named `YYYY-MM-project-short-title.md`, using
[TEMPLATE.md](TEMPLATE.md). Each links to the maintainer's own advisory or fix, and says
plainly what we verified and what we did not. Nothing is listed here before the
maintainer's fix is public or the disclosure window has ended, and entries describe the
class of problem, not how to exploit it.
